# 📊 Projeto Grafos (Python)

Implementação de algoritmos e estruturas de **Grafos** em **Python**, com funcionalidades para construção de grafos, execução de buscas e algoritmos clássicos, além de interface simples de uso via terminal.

---

## 🧠 Descrição

Este projeto reúne implementações de grafos e seus principais algoritmos, como:

- Busca em **Profundidade (DFS)**
- Busca em **Largura (BFS)**
- Algoritmos de caminhos mínimos (Dijkstra)
- Representação de grafos por listas de adjacência

O objetivo é reforçar os conceitos de teoria dos grafos de maneira prática e estruturada.

---

## 📦 Funcionalidades

✔️ Representação de grafos direcionados e não-direcionados  
✔️ Inserção de vértices e arestas  
✔️ Busca em Largura (BFS)  
✔️ Busca em Profundidade (DFS)  
✔️ Algoritmo de Dijkstra para caminho mínimo  
✔️ Impressão do grafo no terminal  
✔️ Interface de fácil uso via console

---

## 📂 Estrutura do Projeto

grafos/
├── main.py
├── grafo.py
├── bfs.py
├── dfs.py
├── dijkstra.py
├── utils.py
└── tests/ (se aplicável)


**Descrição resumida:**
- `main.py`: ponto de entrada e interação com o usuário  
- `grafo.py`: definição da estrutura de grafo  
- `bfs.py`: implementação da BFS  
- `dfs.py`: implementação da DFS  
- `dijkstra.py`: algoritmo de caminho mínimo  
- `utils.py`: utilitários (print, helpers)

## ▶️ Como rodar

1. Clone o repositório:
```bash
git clone https://github.com/caiodantass/GRAFOS.git
```

2. Entre na pasta:
```bash
cd GRAFOS
```

4. Execute o programa:
```bash
python main.py
```

## 🧪 Exemplos de uso

Ao rodar o main.py, serão exibidas opções como:

- Inserir vértices

- Inserir arestas

- Executar BFS

- Executar DFS

- Caminho mínimo (Dijkstra)

Basta digitar as opções conforme o menu do console.
